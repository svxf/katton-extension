# katton language support

syntax highlighting, autocomplete, hover docs, linting and token export/import for Katton (`.kat`) scripts

## how install

1. in VSCode: Extensions view -> `...` menu (top right) -> **Install from VSIX...**
2. pick `katton-lang-0.2.0.vsix`
3. reload when added and then open/create a `.kat` file and done!

## how to build

1. download this repo
2. do `vsce package`
3. thats it
